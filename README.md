# UPTALINK Interfaz
Software profesional para el cálculo y diseño de radioenlaces.

## 🚀 Evolución del Proyecto
Este proyecto nació como una herramienta en **Excel VBA** y ha sido migrado a **Python** para aprovechar el poder de:
- **PySide6**: Para una interfaz de usuario moderna y fluida.
- **PyVista**: Integración de motor 3D para análisis de terreno.
- **SQLite**: Gestión eficiente de base de datos de equipos.

## 🛠️ Tecnologías
- Python 3.11.0
- PySide6 / Flet
- Git para control de versiones
